# 🏥 Patient Management System

*a Java program that stores patient info and adds up their procedures*

![Java](https://img.shields.io/badge/Java-ED8B00?logo=openjdk&logoColor=white) ![class](https://img.shields.io/badge/class-CMSC203-c9a0dc)

## 🩺 What is it?

So, this program asks for a patient's info (name, address, phone number, and emergency contact) and then a few medical procedures they had. After that, it prints everything out neatly and adds up the total charges.

It's split into a `Patient` class, a `Procedure` class, and a driver that ties them together.

## 🚀 Running it

```bash
javac *.java
java PatientDriverApp
```

## 💭 What I learned

Mainly, this was one of my first times writing my own classes with multiple constructors, getters, and setters, so it helped me get the basics of OOP down.
